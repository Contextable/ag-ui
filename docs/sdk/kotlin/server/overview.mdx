# kotlin-server

The `kotlin-server` module provides lightweight helpers for exposing AG-UI
compatible endpoints from JVM servers built with Ktor. It is designed to pair
with the existing client SDK so that Kotlin agents can be hosted and consumed
without additional glue code.

## Installation

Add the dependency alongside the client modules you already use:

```kotlin
dependencies {
    implementation("com.agui:kotlin-server:0.2.1")
}
```

## Quick start

Install the AG-UI streaming route inside your Ktor application and return a
flow of `BaseEvent` objects:

```kotlin
import com.agui.server.aguiStreamingAgent
import com.agui.core.types.*
import io.ktor.server.application.*
import io.ktor.server.routing.*
import kotlinx.coroutines.flow.flow

fun Application.module() {
    routing {
        aguiStreamingAgent("/agent") { input ->
            flow {
                emit(RunStartedEvent(threadId = input.threadId, runId = input.runId))
                val messageId = "assistant-${'$'}{input.runId}"
                emit(TextMessageStartEvent(messageId))
                emit(TextMessageContentEvent(messageId, "Hello from Kotlin"))
                emit(TextMessageEndEvent(messageId))
                emit(RunFinishedEvent(threadId = input.threadId, runId = input.runId))
            }
        }
    }
}
```

The helper takes care of serialising each event as newline-delimited JSON and,
if an exception is thrown, emits a `RUN_ERROR` event so the client receives
structured feedback.

## Error handling

If the handler throws an exception after the stream has started, the helper logs
the failure and emits a `RunErrorEvent` with the message and a `SERVER_ERROR`
code. Clients can surface this information to users instead of failing with a
transport error.

## Related utilities

- [`AgUiStreamingEndpoint`](https://github.com/ag-ui-protocol/ag-ui/) – the
  helper showcased above. If you previously used the SSE helper, it remains
  available as `aguiSseAgent` but is now deprecated in favour of HTTP
  streaming.
- Works seamlessly with the `HttpAgent` client in the Kotlin SDK, as covered in
  the module tests.
